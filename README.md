# Shortwave 🎵

AI曲（Suno / Udioなど）を読み込むだけで、ビジュアライザー付きの縦型ショート動画（1080×1920 / MP4）をブラウザだけで書き出せるアプリ。

**→ アプリを開く: https://kazuyatahara.github.io/shortwave/**

- 完全ローカル処理 — 曲も画像もどこにもアップロードされません
- スマホ対応PWA — ホーム画面に追加すればアプリとして起動、オフラインでも動作
- ビジュアライザー4種 / カラー4テーマ / ジャケット・背景画像・背景動画
- 歌詞テロップ（タイミング打ち対応）/ サビ自動検出 / フェードイン・アウト

## スマホへのインストール

- **Android (Chrome)**: ページを開く → メニュー →「アプリをインストール」
- **iPhone (Safari)**: ページを開く → 共有ボタン →「ホーム画面に追加」

## 使い方

1. 曲を読み込む（またはデモ曲でためす）
2. 見た目を選ぶ
3. テキスト・歌詞を入れる
4. 波形で場所を選んで書き出す

## 技術

単一HTML。Web Audio API + Canvas + MediaRecorder。ライブラリ・ビルド・サーバーなし。
